# SAMI BETA v1

Side-design fork of the supplied SAMI v2.4 refined build. It does **not** replace the production-line build.

## Run / host
This is a flat PWA package. Upload the contents of this folder directly to the web root (for example GitHub Pages). `index.html`, `manifest.webmanifest` and `sw.js` are at the root.

For service-worker/PWA installation, serve over HTTPS (or localhost during development). Opening `index.html` directly from a local file system is not equivalent to hosted PWA operation.

## What to inspect first
1. Intelligence home / project dashboard.
2. OHL reference refresh and mapped support display.
3. Ask SAMI project-aware prompts.
4. Community Intelligence beta/trust framework.
5. Existing Explore, Route, Site Plan, Create and Review workflows to check for regression.
